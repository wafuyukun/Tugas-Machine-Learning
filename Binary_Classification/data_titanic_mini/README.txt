========================================================================
MINI DATASETS FOR MACHINE LEARNING EDUCATION
========================================================================

This collection contains 8 simplified datasets designed for teaching 
Machine Learning. 

LANGUAGES INCLUDED:
1. English
2. Français
3. 中文 (Chinese)
4. Português
5. Español

------------------------------------------------------------------------
1. ENGLISH VERSION
------------------------------------------------------------------------

### Overview
These "mini" versions are curated for pedagogical purposes: reduced 
feature sets and basic preprocessing allow students to focus on 
algorithms rather than data engineering.

### Regression Datasets
- co2_mini.csv: consumption (L/100km) vs co2 (g/km). (Premium Gas only)
- house_mini.csv: Predicting price based on size, rooms, and location.
- abalone_mini.csv: Predicting age (Rings) via physical measurements.
- cos_mini.csv: Synthetic data y = cos(x) + noise. Ideal for SVR/Poly.
- passengers_mini.csv: Monthly airline passengers with time index.

### Classification Datasets
- titanic_mini.csv: Binary survival prediction (Sex, Children, Class).
- cancer_mini.csv: Diagnosis using cell nuclei features (incl. texture).
- iris_mini.csv: Setosa (0) vs Virginica (1) using petal dimensions only.

------------------------------------------------------------------------
2. VERSION FRANÇAISE
------------------------------------------------------------------------

### Présentation
Versions optimisées pour la pédagogie : un nombre de colonnes réduit 
permet de se concentrer sur les algorithmes (Régression, Naive Bayes).

### Jeux de données de Régression
- co2_mini.csv : Consommation vs émissions de CO2 (Essence Super).
- house_mini.csv : Prix des maisons selon la surface, chambres, etc.
- abalone_mini.csv : Âge (Rings) via mesures physiques.
- cos_mini.csv : Données y = cos(x). Idéal pour la régression polynomiale.
- passengers_mini.csv : Passagers aériens (Série temporelle).

### Jeux de données de Classification
- titanic_mini.csv : Prédiction de survie (Sexe, Enfant, Classe).
- cancer_mini.csv : Diagnostic via caractéristiques (incl. texture).
- iris_mini.csv : Setosa (0) vs Virginica (1) (Pétales uniquement).

3. 中文版 (CHINESE)
------------------------------------------------------------------------

### 概述
专为教学设计的简化版数据集。减少了特征数量，使学生专注于算法学习。

### 回归数据集
- co2_mini.csv：油耗与二氧化碳排放的关系（仅限高级汽油）。
- house_mini.csv：基于面积、房间等预测房价。
- abalone_mini.csv：通过物理测量预测鲍鱼年龄（环数）。
- cos_mini.csv：合成数据 y = cos(x)。非常适合多项式回归。
- passengers_mini.csv：航空乘客时间序列数据。

### 分类数据集
- titanic_mini.csv：预测生还情况（性别、儿童、舱位）。
- cancer_mini.csv：肿瘤诊断。包含纹理（texture）等特征。
- iris_mini.csv：山鸢尾 (0) 与 维吉尼亚鸢尾 (1) 的二元分类。

### Apresentação
Versões otimizadas para a pedagogia: número reduzido de colunas para 
focar nos algoritmos de aprendizado.

### Conjuntos de dados de Regressão
- co2_mini.csv: Consumo vs emissões de CO2 (Gasolina Premium).

### Conjuntos de dados de Classificação
